# TFG: Sistema de Gestión de Incendios Forestales

Plataforma integral para la monitorización, alerta y coordinación de emergencias por incendios forestales.

## Stack Tecnológico
- **Base de Datos:** PostgreSQL 16 + PostGIS (Docker)
- **Backend:** Node.js, Express, TypeScript
- **Frontend:** React, Vite, TypeScript, Tailwind CSS
- **Entorno de desarrollo:** WSL2 (Ubuntu)
