# Plan de Seguimiento y Control

Este documento define las métricas, metodologías y mecanismos para monitorizar el avance del proyecto según la planificación temporal y de costes (esfuerzo en horas).

## 1. Control del Cronograma y Recursos
* **Herramienta de seguimiento:** Se utilizará Clockify para el registro atómico del tiempo invertido, etiquetado por fases del proyecto.
* **Línea base de tiempo:** El progreso se comparará quincenalmente contra las 300 horas estimadas en el Plan de Proyecto.
* **Control de desviaciones:** Si una iteración consume más del 15% del tiempo estimado, se evaluarán las solicitudes de cambio o se recortará alcance no crítico previo acuerdo con el tutor.

## 2. Gestión de Riesgos e Incidencias
* Las incidencias técnicas (bugs) se registrarán como nuevas *Issues* en ZenHub con la etiqueta `fix` y entrarán en la bandeja `New Issues`.
* El seguimiento de riesgos identificados en el Plan de Proyecto se evaluará al inicio de cada nueva iteración.

## 3. Revisión de Progreso (Comunicaciones con el Tutor)
* Se establecerán reuniones de revisión de entregables e hitos.
* De cada reunión se generará un registro formal mediante la plantilla "Acta de Reunión", documentando los acuerdos alcanzados y el feedback sobre los productos entregados.
